# Папка для установщика лаунчера

Положи сюда собранный установщик:

```
downloads/THETOWN-Setup-1.0.0.exe
```

Сайт ищет файл по этому пути (`LAUNCHER_FILE` в `index.html`) и отдаёт его по кнопкам
«Скачать лаунчер». Пока файла нет, кнопки показывают уведомление «установщик ещё не загружен».

Как собрать установщик — см. `../СБОРКА.md` (коротко: `cd launcher && npm install && npm run dist`).

Для GitHub Pages файл >100 МБ нужно класть через Git LFS или GitHub Releases —
подробности в `../СБОРКА.md`.
